# Analyzing Content Moderation on Mastodon

This project analyzes the community moderation policies of Mastodon, a federated social network that saw a surge of new users in October 2022 following Elon Musk's acquisition of Twitter. Unlike centralized platforms, Mastodon delegates moderation to individual server administrators, making it an ideal setting for studying how community size, federation structure, and instance identity shape rule-writing behavior.

## Overview

We collected rules from ~6,500 Mastodon instances in October 2023 — exactly one year after the Twitter exodus — via the Mastodon API. For each instance we recorded community rules (translated to English), user counts, federation peer lists, and instance creation dates. We then applied GPT-4o-mini one-shot prompting to categorize each rule into one of 20 topic types.

Our analyses examine:
- **Topic coverage:** How many distinct rule topics do instances address, and how does this vary with instance size?
- **Lexical complexity:** How do word count, type-token ratio, and Flesch-Kincaid readability differ across instance sizes?
- **Topical diversity:** Shannon entropy of rule-topic distributions as a measure of breadth.
- **Regression modeling:** OLS, Negative Binomial, and Beta regression linking lexical features to instance size, federation, and age.
- **Robustness checks:** Deduplication, translation validation, engagement-based replication, and Wayback Machine pre/post-Elon snapshot comparisons.
